## Get Started
For a Chromium-based browser (e.g. Brave, Google Chrome), you can [download from the Chrome Web Store](https://chromewebstore.google.com/detail/filtered/bhcdiggpokngbonamlfgihnkjdeepmdg).
For a Firefox-based browser (e.g. LibreWolf, Zen), you can [download from Firefox Add-ons](https://addons.mozilla.org/en-GB/firefox/addon/filtered/).


Or, manually:

Clone or [download](https://github.com/galib-i/filtered/releases/latest) (and unzip) this repository, then load it into your browser:

For Chromium-based browsers:
  1. Open your browser's extensions page (`chrome://extensions/`).
  2. Toggle the "Developer mode" switch in the top right corner.
  3. Click "Load unpacked" and select this project's folder.

For Firefox-based browsers:
  1. Open `about:debugging` in your browser.
  2. Click "This Firefox" in the left sidebar.
  3. Click "Load Temporary Add-on..." and select `manifest.json` from the project's folder.
